# AGENTS.md — not the operating manual for this fork

**This is `grove-autonomaton`, a Grove Foundation fork of NousResearch's
hermes-agent.** The upstream "Hermes Agent — Development Guide" that used to live
here has been removed: it predates the fork and knows nothing about the
conventions this repo actually runs on. Left in place, it steered
`agents.md`-honoring tools (Codex, Cursor, etc.) wrong.

**Read `CLAUDE.md` instead** (project root). It is authoritative for every
agent — Claude Code or otherwise — and covers how work happens here: the
Autonomaton Pattern, the Foundation Loop sprint discipline, Notion as the
source of truth (planning lives there, not in-repo), and the fail-loud /
declarative-governance commitments.
